# 悦动生活综合工作室\-预约流程与到店规范\.md

## 商户基础信息

悦动生活综合工作室所有健身私教、肩颈理疗推拿服务、团课服务均实行**全预约制**，无预约不接待临时到店服务。为规范服务流程、保障客户服务体验、合理分配教练及理疗师档期，门店制定统一预约、改期、取消、爽约、到店服务规范，所有客户到店消费均需严格遵守本流程规则。

# 一、官方唯一预约方式

门店仅开放两种有效预约渠道，所有预约记录以系统存档、微信文字记录为准，任何口头预约均无效，不纳入服务凭证。

## 1\.1 优先预约渠道：工作室微信小程序预约

为官方主推、最高优先级预约方式，操作自主、实时生效、可自主改期取消，全程无人工干预，订单状态实时同步。具体操作流程：客户打开门店专属微信小程序，完成手机号授权登录，根据需求选择【健身私教】或【肩颈理疗】服务项目，自主选择心仪教练/理疗师、可选空闲时段，核对预约信息后提交预约，系统提示预约成功即为生效。

## 1\.2 辅助预约渠道：客服微信人工预约

针对中老年客户、不熟悉小程序操作的客户，可添加门店专属客服微信，通过**微信文字留言**方式告知客服预约项目、预约日期、意向时段、个人手机号，由客服协助人工登记预约。仅文字确认有效，语音、电话口头告知不计入有效预约。

## 1\.3 无效预约方式说明

**不接受任何电话口头临时预约**，所有电话咨询仅作为答疑沟通渠道，无法锁定档期、无法生成有效预约订单。任何电话口头约定的服务时段，门店不予认可，不保留服务名额，敬请所有客户知悉。

# 二、预约提前时间规范

为保障门店合理排期、预留充足服务准备时间、避免档期冲突，针对不同时段预约设置明确的提前预约标准，高峰时段需提前锁定档期。

- **日常时段预约**：工作日私教课程、肩颈理疗项目，建议提前1\-3天预约，可自由选择心仪教练、优质时段，档期充足。

- **周末及节假日高峰预约**：周六、周日及所有法定节假日为服务高峰期，客流集中、档期紧张，**必须至少提前3天预约**，方可有效锁定服务时段，临时预约大概率无可用档期。

- **团课预约**：团课建议提前1\-2天预约，方便门店统计人数，确认是否正常开课，避免课程取消影响客户计划。

# 三、预约改期详细规则

客户预约成功后，因个人时间变动需要调整服务日期、时段的，可申请免费改期，改期需遵守时间限制，超时改期将判定为爽约。

- **有效改期时限**：客户如需改期，必须在**距离预约服务开始时间6小时以上**，通过小程序自主操作或微信联系客服提交改期申请。

- **免费改期权益**：6小时以上申请改期，无任何违约记录、不扣除课时、不收取手续费，可免费调整至其他空闲时段。

- **超时改期处罚**：距离服务开始不足6小时申请改期的，系统自动判定为一次爽约，按照爽约规则执行处罚，无法豁免。

- **改期次数说明**：单次预约仅支持一次改期，多次频繁改期门店有权限制预约权限，保障档期资源合理利用。

# 四、预约取消与爽约判定及处罚规则

为杜绝档期资源浪费、保障所有客户的预约权益，门店设立严格的取消预约与爽约管理机制，所有判定标准系统自动执行，公平统一。

## 4\.1 无违约取消规则

客户在**服务开始6小时以上**，通过小程序或客服成功取消预约，视为正常取消，**不计入爽约记录**，已预约的课时、理疗次数会原路退回客户个人账户，可后续正常使用，无任何损失。

## 4\.2 爽约判定标准（满足任意一条即判定爽约）

- 距离服务开始不足6小时临时取消预约；

- 预约成功后未按时到店、全程未到店参与服务；

- 客户到店迟到超过20分钟，且未提前告知客服、未申请改期，视为自动放弃当次服务。

## 4\.3 爽约处罚机制

- 单次爽约：直接**扣除1次对应课时/理疗次数**，不予返还、不予补偿；

- 月度累计处罚：单个自然月内，客户累计爽约达到3次，系统自动**限制该账户所有预约权限**，禁止一切预约操作；

- 权限解除方式：被限制预约后，需客户主动联系客服，说明情况并申请解除限制，经客服核实登记后方可恢复预约权限。

# 五、到店前置准备须知

## 5\.1 健身私教客户到店准备

参与私教训练的客户，需**自备专业运动服、防滑运动鞋**，保障运动安全与训练体验。门店免费提供常温饮用水，可自带水杯接取；运动毛巾、擦汗用品建议客户自行携带，门店不统一提供免费毛巾，如需使用门店毛巾可咨询客服另行消费。训练前建议空腹1小时或少量进食，避免饱腹运动引发不适。

## 5\.2 理疗推拿客户到店准备

体验肩颈理疗推拿的客户，不建议餐后立即到店服务。为避免推拿过程中出现腹胀、恶心、不适等情况，**建议饭后至少间隔1小时再到店体验理疗**。同时建议穿着宽松、舒适、透气的衣物，方便理疗师操作，提升放松效果。

# 六、理疗项目禁忌人群说明

肩颈理疗推拿为物理放松项目，存在明确适配与禁忌人群，为保障客户身体健康与安全，以下人群**不建议参与门店推拿理疗项目**，请严格遵从医嘱：

- 严重高血压、心脑血管疾病患者；

- 身体存在急性扭伤、拉伤、红肿发炎部位的人群；

- 皮肤表面有破损、伤口、过敏、炎症、皮肤病的人群；

- 孕期女性客户；

- 其他医生明确禁止推拿、按摩的特殊身体状况人群。

如有不确定身体状况，可提前咨询客服或理疗师，确认无误后再预约理疗项目。

# 七、到店后标准服务流程

1. **前台签到**：客户按时到达工作室后，直接前往前台，告知预约预留的手机号，前台工作人员核对预约信息，完成签到登记；

2. **等待接待**：签到完成后，在门店休息区安静等候，无需自行联系教练/理疗师；

3. **专属服务**：对应预约的私人教练或理疗师会主动接待客户，带领客户进入对应服务区域，开启课程训练或理疗服务；

4. **服务结束**：服务完成后，教练/理疗师会做简单总结与居家养护指导，客户可自行离场，无需额外操作。

门店日常营业区分工作日与周末两套时间标准，正常无特殊通知、无节假日、无设备维护时，统一执行以下营业时间，前台接待、教练授课、理疗服务、客服咨询均在对应时段内提供服务。

# 三、法定节假日营业调整规则

针对全国统一大型法定节假日，门店执行动态营业时间调整，区别于常规营业时间，节假日服务资源有限，全部项目均需提前预约，不接受临时到店。

## 3\.1 通用节假日营业时间

五一劳动节、国庆节、元旦等大型法定节假日期间，门店统一调整营业时间为：10:00\-18:00。相较于日常时间缩短营业时长，集中提供优质服务，18:00后全面闭馆，停止一切服务。

春节为年度长假，门店执行专属休馆政策：除夕至正月初三**全天闭馆休息**，四天时间完全暂停所有线下服务，无课程、无理疗、无前台接待、无现场服务。正月初四起根据当年假期安排恢复节假日营业时间或常规营业时间，具体以节前公示通知为准。

## 3\.3 节假日预约硬性要求

所有法定节假日期间，无论是私教课程还是肩颈理疗项目，**必须提前通过小程序或客服完成线上预约**，严格锁定服务时段与服务人员。门店不接受任何临时到店、无预约空降服务，未预约客户到店无法提供对应项目服务，敬请谅解。节假日预约同样遵循改期、取消、爽约通用规则。
